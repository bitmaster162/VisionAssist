# VisionAssist Lineage R29 Evidence

This directory preserves the user-supplied R29 correction and its four-row
lineage table.

Evidence classes:

- `HISTORICAL_ORIGIN`: the old SensorBridge scaffold was physically observed.
- `ARCHIVE_PIVOT`: the R29 source records the chart-semantic transition.
- `RESEARCH_ARCHITECTURE`: Active Inference is a method lineage claim, not a
  completed-runtime claim.
- `CURRENT_OPERATOR_CANON`: visual-semantic cognition and human-AI fusion
  define current identity, while benchmark value remains unproven.

`receipt.json` records the supplied source hashes. The Markdown copy is
byte-identical. The CSV repository copy differs only because CRLF line endings
were normalized to LF.
