# VisionAssist Lineage R29

`visionassist_lineage.json` is the machine-readable identity and portfolio
contract for VisionAssist.

It fixes four sequential stages:

1. Assistive vision is the historical origin and optional accessibility adapter.
2. Chart semantics is the pivot that reframed charts as noisy visual worlds.
3. Active Inference is the research method, not an implementation claim.
4. Visual-semantic cognition and human-AI fusion are the current operator canon.

The current core profile is `intent-r26`. The mobile `android-pilot` remains
available only as an explicitly selected adapter. The primary evidence gate is
`VISIONASSIST_CHART_INTENT_AND_HUMAN_AI_FUSION_PROOF`.
